# مجلد السيرفر القديم (Node.js)

هذا المجلد يحتوي على الملفات القديمة الخاصة بسيرفر Node.js/Express.

## الملفات:
- `server.js` - السيرفر القديم (تم استبداله بـ server.php)
- `package.json` - تبعيات Node.js
- `package-lock.json` - قفل التبعيات
- `node_modules/` - المكتبات المثبتة
- `update-api-paths.ps1` - سكريبت PowerShell للتحديث

## ملاحظة:
هذه الملفات **لا تحتاجها** في الاستضافة الجديدة.
المشروع الآن يعمل على PHP فقط.

يمكنك الاحتفاظ بها كنسخة احتياطية أو حذفها.
